How it is configured, and how the number was chosen

AN ANN INDEX, EIGHT CENTROIDS, MEASURED THRESHOLD

var vector = VectorIndexConfiguration(

  expression: "embedding",

  dimensions: 768, centroids: 8)

vector.metric = .cosine

vector.encoding = .none

try reports.createIndex(

  withName: "idx_reports_embedding",

  config: vector)

Why these values

768 — what Vision's feature print revision 2 produces.

8 centroids — about the square root of the reports on one phone; raise it as the corpus grows.

Cosine, and no quantisation: at this size there is nothing to save.

The plan started at 0.35, which matched any two potholes. The measurements moved it to 0.15. Mac-computed and device-computed vectors for the same bytes differ by 2.1e-4 — far inside that margin.

The message for an engineer in the room: you measure this threshold on your own photographs with your own model. The app has a developer screen that prints the raw distances of the last check, which is how this table was produced.
