THE DATABASE IS ON THE PHONE

Airplane mode, and the app is not degraded — it is home. The list, the photographs, the filters and the search all come out of Couchbase Lite, a real embedded database with collections, indexes and transactions.

How it is built

Couchbase Lite Swift Enterprise 4.1.2, one Swift package.

The same scope and collection names as Capella: evidence.reports, evidence.photos. Nothing is renamed in transit.

Every capture is one inBatch transaction: report, photo and the parent update land together or not at all.

The list is driven by a collection change listener, so a status set by a supervisor updates it with no polling code.

The amber banner is pinned above the list on purpose, so the audience can always see what the network is doing. Turn on Simulate offline before this slide if you are showing the live app. The point to land: this is not a cache with a sync queue bolted on — it is a database that happens to replicate.
